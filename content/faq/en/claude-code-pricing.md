# How Much Does Claude Code Cost?

**Claude Code** is included with your Claude subscription plan. [Pro](/glossary/claude) costs **$20/month** ($200/year), while **Max 5x** is **$100/month** and **Max 20x** is **$200/month**. Free accounts have limited access. Max subscriptions are dramatically cheaper than paying Claude API rates directly — users report up to 93% savings compared to equivalent API usage.

## Context

Claude Code pricing confusion stems from the fact that it's not a separate tool — it's a feature bundled into your Claude subscription tier. The Free and Pro plans include Claude Code access, but Max plans (5x and 20x) give you higher usage capacity per session.

To understand if a subscription makes sense, consider the math: a single user doing heavy development work can consume 2–10 billion tokens monthly. Via the Claude API, that would cost $3,650–$15,000. The Max 20x plan at $200/month represents a 18x discount relative to API pricing. Even Max 5x at $100/month is substantially cheaper than API rates for medium-to-heavy usage.

Pro ($20/month) is suitable for light work — occasional code generation and small refactoring tasks. But sustained daily development sessions will exhaust Pro's usage limits quickly. Max plans are designed for developers who use Claude Code as their primary coding tool. Team and Enterprise plans exist for organizations; contact Anthropic for custom pricing.
