# Claude Code pricing: API vs Max vs Pro

Claude Code itself has no separate license fee. You access it through three pricing tiers: API pay-per-token billing with variable costs based on usage, Claude Pro at $20 per month with included but limited Claude Code access, or Claude Max at $100 to $200 per month with high usage caps designed for professional developers.

## Context

[Anthropic](/glossary/anthropic) structured [Claude Code](/glossary/claude-code) pricing around the reality that agentic coding sessions consume far more tokens than standard chat. When Claude Code reads your codebase, plans changes across multiple files, executes commands, and iterates on results, a single session can use tens of thousands of tokens. This makes choosing the right pricing tier a meaningful decision for your workflow and budget.

The API tier charges per input and output token, with rates varying by model. Opus costs more per token than Sonnet, so routing simpler tasks to lighter models is a common cost optimization. Some active developers report $50 to $150 per month in API costs depending on session frequency and complexity.

[Claude](/glossary/claude) Pro at $20 per month includes Claude Code access but with conservative rate limits. It works well for occasional use — a few sessions per day — but power users will hit ceilings quickly. Claude Max comes in two tiers: $100 per month and $200 per month, each offering progressively higher usage caps, priority capacity, and better rate limits during peak hours.

Enterprise teams get additional options including volume pricing and team management features. ## Practical Steps

1. Start with Claude Pro at $20 per month to evaluate whether Claude Code fits your daily workflow
2. Track your usage patterns for one to two weeks — note how often you hit rate limits and how many sessions you run per day
3. If you consistently run out of capacity before the workday ends, upgrade to Claude Max at $100 per month
4. For API billing, use model routing strategically: Sonnet for quick edits and searches, Opus for multi-file refactoring and complex debugging
5. Monitor costs through Anthropic's usage dashboard, which breaks down token consumption by session
6. For teams, evaluate enterprise plans that offer volume discounts and centralized billing
