# OpenAI Codex 怎么下载安装？

**OpenAI Codex** 本身不是一个独立的桌面应用，无法像普通软件那样直接下载安装。它是一个云端 AI 编程智能体，目前通过三种方式接入：VS Code 扩展、CLI 工具，以及 ChatGPT 网页界面。

## 三种接入方式

**Codex 没有独立的安装包**，但你可以根据工作场景选择适合的接入方式。

**1. VS Code 扩展**
在 VS Code 的扩展市场搜索"Codex"或"OpenAI"，即可安装官方扩展。安装后在 IDE 内直接调用，无需离开编辑器。详见我们的 VS Code 扩展使用指南。

**2. Codex CLI**
适合习惯终端操作的开发者。通过 `npm install -g @openai/codex` 安装后，在命令行直接与代码库交互。关于上手体验，参考初识 Codex CLI。

**3. ChatGPT 网页端**
ChatGPT Plus 及以上用户可在网页界面访问 Codex 智能体，适合轻量任务或不想配置本地环境的场景。

## 平台支持

Codex CLI 支持 macOS 和 Linux，Windows 用户需通过 WSL（Windows Subsystem for Linux）运行。VS Code 扩展三大平台均可使用。完整的功能和架构说明见 Codex 完全指南。
