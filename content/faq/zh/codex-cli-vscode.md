# 如何在 VS Code 中使用 Codex CLI？

**可以。** OpenAI Codex 为 VS Code 提供了官方扩展，同时 Codex CLI 也能在 VS Code 的集成终端中运行。两种方式都能让你在 VS Code 中访问云端编程智能体功能——选择哪一个取决于你的工作流偏好。

## 背景

Codex 是 OpenAI 推出的云端编程 AI 代理，专为自动化编码任务而设计。VS Code 中有两种方式使用 Codex：一是安装 官方 Codex VS Code 扩展，直接在编辑器内交互；二是通过 CLI 在终端执行命令。

如果你是 Codex CLI 的新手，初识 Codex CLI 的前几天会介绍快速上手的关键点。完整的技术细节与最佳实践见 Codex 完全指南。

## 常见选择

- **选择 VS Code 扩展**：如果你希望在编辑器内有原生的 UI 界面，快速访问 Codex 功能
- **选择 CLI**：如果你习惯命令行工作流，需要与脚本或其他工具集成
- **两者结合**：许多开发者同时使用两种方式，在不同场景下切换

详细的安装和配置步骤，请参考 Codex CLI 使用指南 和相关的 配置文档。
