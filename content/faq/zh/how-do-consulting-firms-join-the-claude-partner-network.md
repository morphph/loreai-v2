# 咨询公司如何加入 Claude Partner Network？

咨询公司需要通过 **Anthropic** 官方渠道提交合作申请，经过资质审核后加入 **Claude Partner Network**。该计划面向具备企业级 AI 落地能力的咨询与系统集成公司，帮助它们将 Claude 集成到客户的业务流程中。

## 背景

Anthropic 在 2024 年推出了 Claude Partner Network，旨在构建一个围绕 Claude 的企业服务生态。随着越来越多的大型企业希望部署 Claude 来提升效率，Anthropic 意识到仅靠自身团队无法覆盖所有行业和场景，因此选择与咨询公司合作，借助它们的行业经验和客户关系来加速 Claude 的企业采用。

目前已知的合作伙伴包括 Accenture、BCG、Deloitte、McKinsey 等全球顶级咨询公司。这些公司通过合作获得 Anthropic 的技术培训、优先 API 支持以及联合市场推广机会。该计划也与 Anthropic 在 [AI 安全](/glossary/ai-safety)方面的承诺一致——合作伙伴需要遵守负责任的 AI 使用准则。

更多关于 Anthropic 生态战略的信息，可以访问我们的 [Anthropic 专题页](/topics/anthropic)。

## 实际步骤

1. **确认资质**：公司需具备企业级 AI 咨询或系统集成经验，最好已有 Claude API 的使用案例
2. **提交申请**：通过 Anthropic 官网的合作伙伴页面提交申请，说明公司背景、服务能力和目标客户群
3. **资质审核**：Anthropic 团队会评估申请公司的技术能力、行业覆盖和客户基础
4. **签署协议**：通过审核后，双方签署合作协议，明确技术支持、品牌使用和数据合规等条款
5. **启动合作**：获得技术培训资源、合作伙伴标识以及 Anthropic 团队的直接支持通道

需要注意的是，Anthropic 对合作伙伴的 [AI 安全](/glossary/ai-safety)实践有明确要求，申请时展示对负责任 AI 部署的理解会是加分项。
