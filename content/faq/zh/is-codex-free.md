# Codex 免费吗？

**[Codex](/glossary/codex)** 本身没有独立定价，它包含在 [ChatGPT](/zh/glossary/chatgpt) 的现有订阅计划中。目前 ChatGPT Pro、Business、Enterprise 和 Plus 用户均可使用 [Codex](/zh/blog/codex-complete-guide)，无需额外付费。但 OpenAI 已明确表示，这一"慷慨访问"阶段是限时的——后续将推出带速率限制的免费额度，以及按需购买额外用量的付费选项。

## 背景

Codex 于 2025 年 5 月作为"研究预览"发布，首批开放给 Pro、Business 和 Enterprise 用户，随后在 6 月扩展到 Plus 用户。OpenAI 采用了典型的渐进式发布策略：先让付费用户免费体验以收集反馈，再逐步收紧用量并引入商业化定价。

值得注意的是，Codex 的使用场景分两条线：

- **ChatGPT 内的 Codex 代理**：通过 ChatGPT 侧边栏访问，运行在云端沙箱中，目前随订阅计划提供
- **[Codex CLI](/zh/glossary/codex-cli)（命令行工具）**：开源免费，但调用 API 需要单独付费。默认使用的 `codex-mini-latest` 模型定价为每百万输入 token $1.50、每百万输出 token $6.00，缓存命中享 75% 折扣

OpenAI 还为通过 ChatGPT 账号登录 Codex CLI 的用户提供了限时 API 额度：Plus 用户 $5、Pro 用户 $50，有效期 30 天。想了解 Codex 的完整功能，可以参考我们的 [Codex 完全指南](/blog/codex-complete-guide)。

## 实用建议

1. **ChatGPT 订阅用户**可以直接在 ChatGPT 中使用 Codex，当前阶段无额外费用
2. **Codex CLI 用户**先用 ChatGPT 账号登录领取免费 API 额度，再决定是否继续付费使用
3. 关注 OpenAI 官方公告，正式定价方案尚未公布，当前的免费额度随时可能调整
4. Edu 用户的支持计划已列入路线图，但具体时间未公布
