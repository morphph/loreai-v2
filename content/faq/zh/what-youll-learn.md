# 学习 Claude Code 你能掌握什么？

系统学习 **Claude Code** 后，你能独立完成从单文件修改到跨仓库重构的全流程 AI 编程任务，并具备将 AI Agent 嵌入真实工程工作流的能力。

## 核心能力

学完之后，你将能够熟练操作 Claude Code 的七层架构——从基础的终端命令，到 Skills、Hooks、Agents、MCP 四层扩展栈。这篇拆解文章对四层架构有详细说明。

具体来说，你会掌握：

- **CLAUDE.md 与 SKILL.md 的编写规范**：让 AI 理解你的项目上下文和工程标准，避免重复提示
- **Hooks 的配置与调试**：在代码提交、测试运行等关键节点插入自定义逻辑，实现真正可控的 AI 编程。详见Hooks 深度指南
- **多 Agent 协作模式**：通过 Claude Code Agent Teams 拆解复杂任务，并行执行，适合大型单体仓库
- **MCP Server 集成**：将数据库、外部 API、监控系统接入 Claude Code 工作流

## 适合谁来学

这套内容适合已有终端使用习惯的工程师，尤其是：

- 想从「AI 辅助写代码」升级到「AI 自主执行任务」的开发者
- 负责工程效能、希望在团队内规模化推广 AI 工具的 Tech Lead
- 对 agentic coding 感兴趣、想构建自己 Agent 工作流的独立开发者

如果你更倾向于 IDE 内的行内补全，Claude Code vs Cursor 对比可以帮你判断哪个工具更适合你的工作方式。
