## 🔬 RESEARCH

### One model, two harnesses, a 29-point score gap

An agent benchmark can change dramatically without changing the model. **Hugging Face** reports that identical model weights scored 62% in one harness and 33% in another. Its guide describes training across multiple harnesses through a proxy approach, a useful direction for anyone trying to build agents that work beyond one evaluation setup. (332 likes | 58 RTs) [Read more →](https://x.com/huggingface/status/2106034221005312448)

### The agent claimed success; the database told another story

A confident “done” is worthless if the underlying state says otherwise. **Microsoft**’s ThinkingBox post examines an agent completion claim that disagreed with database state. For builders, the lesson is concrete: verify the result in the system the agent was supposed to change. [Read more →](https://huggingface.co/blog/microsoft/thinkingbox)

**Wavestone AI Lab** proposes a seven-part blueprint for agent harnesses after reportedly comparing 11 agents, including Claude Code and Codex. The framework could give builders a sharper checklist for system design and evaluation. Read the paper before adopting its categories as settled fact. (125 likes | 8 RTs) [Read more →](https://x.com/undefinedKi/status/2106479644354474463)

## 🎓 MODEL LITERACY

**Agent harness effects in evaluation**: A harness is the surrounding system that gives a model tools, instructions, and a way to act across steps. Change that system and the model can perform very differently: the same weights reportedly scored 62% in one harness and 33% in another. When someone cites an agent benchmark, ask how the agent was equipped and run. The score measures that setup as well as the model.
