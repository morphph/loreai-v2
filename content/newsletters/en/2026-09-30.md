## 🔬 RESEARCH

### An Agent Can Get the Fact Right From the Wrong Source

A plausible answer can conceal a bad evidence trail. **Source-Aware Verification for MCP Agents** asks whether an agent consulted the appropriate source as well as returned the right fact. That distinction matters when an agent can search, choose tools, and act over time: a lucky answer today can become a costly mistake tomorrow. Add source choice to your agent evals. [Read more →](https://huggingface.co/blog/MultiverseComputingCAI/getting-the-source-right-not-just-the-fact-source)

## 🎓 MODEL LITERACY

**Source-aware verification** checks an agent’s evidence path, not only its final answer. The MCP agent research asks whether the agent used the right source to produce a fact. Imagine an always-on agent such as Dots giving the correct figure from an outdated document: an answer check might pass, while a source check catches the fragile method. Evaluating both tells you more about whether the next answer will hold up.

## 🎯 PICK OF THE DAY

**The right answer is no longer enough.** The source-aware MCP agent research gets at the weak spot in longer-running agents: a correct fact can come from an inappropriate source, leaving a plausible result built on shaky evidence. As products such as Dots take on work over time, builders need to check which source an agent chose, not merely whether its last sentence sounded right. My take: source choice belongs in the eval suite beside answer accuracy. Otherwise, teams will reward agents for getting lucky.
