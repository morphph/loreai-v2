## 🔧 开发者工具

### Claude Code Mods 让团队工作流可以共享。

团队如果各自维护一套 Claude Code 用法，现在有了把改动做成插件、交给同事复用的路径。**Claude Code Mods** 支持定制工作环境，并把这些定制分享出去。先从一项重复率最高的团队流程试起，看它是否真的减少配置成本。[详情 →](https://www.claude.com/blog/claude-code-mods)

### DeepSeek 为华为 AI 芯片开出软件路径。

使用华为 AI 芯片的团队，训练和推理能否落地，关键还在代码怎么跑起来。**DeepSeek** 开源了面向这些芯片的软件工具，其中包括兼容版本的 **TileLang**。这一步有实际分量：它为开发者提供了可检查的软件路径，但具体性能仍要在自己的负载上测。[详情 →](https://www.theinformation.com/briefings/deepseek-open-sources-software-tools-huawei-ai-chips)

**Pi 1.0 降低 Codemode 的提示词消耗。** 已在使用 **Pi** 的开发者可以重点复测成本：新版称 Codemode 的提示词 Token 用量减少约 40%，还加入图像生成并加强了 MCP OAuth。终端界面现在默认全屏；想保留常规滚动记录，可设置 `tuiMode: "regular"`。(292 likes | 25 RTs) [详情 →](https://x.com/PiChangelog/status/2105741334728634552)

## 🎓 模型小课堂

**GPU 算子可移植性（GPU kernel portability）**：模型训练和推理要调用底层计算程序，也就是 GPU 算子。换一款芯片时，即使拿到了硬件，原有算子也未必能直接运行或保持原来的速度。DeepSeek 的华为兼容 TileLang 工具之所以值得关注，正是因为它尝试给代码迁移提供路径。实际迁移仍需逐项验证能否运行、结果是否正确，以及性能表现。[详情 →](https://www.theinformation.com/briefings/deepseek-open-sources-software-tools-huawei-ai-chips)
