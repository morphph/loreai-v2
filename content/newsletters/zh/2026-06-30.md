# Anthropic 推出 Claude Apps Gateway，Bedrock 和 Vertex 用户直接用上消费级功能

## 🧠 发布动态

### Anthropic 推出 Claude Apps Gateway，Bedrock 和 Vertex 用户直接用上消费级功能。
企业用 Claude 最大的摩擦是什么？明明 AWS/GCP 已经有账单关系，却要单独开 Anthropic 账号才能用 Projects、Artifacts、MCP 集成这些好东西。现在这个门槛没了 — 新推出的统一网关让企业直接通过现有的 Bedrock 和 Vertex AI 账单访问 Claude 全套应用功能。如果你的团队在 AWS 或 GCP 上，去看看是否符合接入条件。 [详情 →](https://www.claude.com/blog/introducing-the-claude-apps-gateway)

AWS、GCP、Azure — Anthropic 用不到一周时间完成了超大规模云平台的三杀。被锁在 Azure 生态里的企业团队，现在不用再为用 Claude 单独搞一套账单了。对 Anthropic 来说，这是分发策略的关键一步：不跟云厂商抢客户，而是把自己嵌进每一个云厂商的生态里。 [详情 →](https://www.claude.com/blog/claude-in-microsoft-foundry)

## 🎓 模型小课堂

**NPU vs GPU — 为什么有些模型在手机上飞快，有些却卡成幻灯片？**：你可能听过 GPU（图形处理单元），它是目前大模型训练和推理的主力。但你的 iPhone 和 Mac 里还藏着一个 NPU — 神经处理单元（Neural Processing Unit）。GPU 像一个万能工人，什么活都能干，但功耗高；NPU 是专门为神经网络矩阵运算设计的，功耗低、速度快，但只擅长特定类型的计算。苹果刚发的 ANE 架构论文首次揭开了 NPU 的黑箱 — 为什么有些模型在设备端飞快？因为它们的计算模式恰好匹配 NPU 的硬件设计。随着推理从云端向终端迁移，理解 NPU 的约束条件正在变成开发者的必修课。
