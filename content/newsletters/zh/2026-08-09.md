## 🎓 模型小课堂

**消息传递 vs. 共享状态：多 Agent 系统的两条路**：当多个 AI Agent 需要协作时，它们怎么交换信息？主要有两种方式。**消息传递**（Message Passing）就像微信群聊 — 每个 Agent 明确地给其他 Agent 发消息，说"我做完了，结果是 X"。**共享状态**（Shared State）更像一块共享白板 — 所有 Agent 都能读写同一块数据，谁需要什么自己去看。Claude Code 的跨会话消息选择了消息传递路线：更安全、更可控、不容易出现多个 Agent 同时改同一个东西导致冲突的问题，但代价是需要更多显式的协调逻辑。理解这个架构分叉，对你选型或设计自己的多 Agent 系统至关重要。
