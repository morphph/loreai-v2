模型小课堂

消息传递 vs. 共享状态：多 Agent 系统的两条路：当多个 AI Agent 需要协作时，它们怎么交换信息？主要有两种方式。消息传递（Message Passing）就像微信群聊 — 每个 Agent 明确地给其他 Agent 发消息，说"我做完了，结果是 X"。共享状态（Shared State）更像一块共享白板 — 所有 Agent 都能读写同一块数据，谁需要什么自己去看。Claude Code 的跨会话消息选择了消息传递路线：更安全、更可控、不容易出现多个 Agent 同时改同一个东西导致冲突的问题，但代价是需要更多显式的协调逻辑。理解这个架构分叉，对你选型或设计自己的多 Agent 系统至关重要。

今日精选

每个 Agent 框架都在重新发明编排 — 这不是功能蔓延，而是重力：Claude Code 上线跨会话消息、Auto 模式默认开启、OpenAI 的 Agent 意外 DDoS 事件 — 把这些连起来看，一个清晰的趋势浮现：独立运行的单 Agent 是不稳定态。就像 Zawinski 观察到每个 Unix 工具最终都会长出邮件功能，现在每个 Agent 框架都在向内置编排能力收敛。跨会话消息传递只是最新的证据 — Agent 需要协调，而协调需要通信原语，而通信原语最终会演变成完整的编排层。对开发者的启示很直接：不要再把"单 Agent + 外部胶水"当作长期架构了。选框架时，看它的编排故事是否原生、是否可扩展 — 因为你迟早需要它。 详情 →
