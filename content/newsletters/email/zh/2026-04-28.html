1. 微软和 OpenAI 终止独家合作与营收分成。

2. gpt-realtime-1.5：语音变成完整的应用控制器。

OpenAI 发布 gpt-realtime-1.5，用户现在可以用自然语音直接控制应用状态 — 这不是"语音转文字再执行命令"，而是语音作为原生 UI 控制层。语音助手和完整交互应用之间的那道墙正在消失。如果你在做任何需要 hands-free 交互的产品，现在就该用 Realtime API 搭个原型试试。 →

3. 小米开源 MiMo-V2.5 — 专为 1000+ 工具调用设计的 Agent 模型。

MiMo-V2.5-Pro 专门针对长周期 Agent 任务优化：支持 1000+ 连续工具调用、强指令跟随、超长上下文一致性。MIT 协议，可商用部署，vLLM 首日就支持。如果你的 Agent 工作流需要长链条工具调用，拿它和你现在的 backbone 跑个对比 — 国产开源模型在 Agent 场景上的竞争力越来越强。 →

模型小课堂

Agent 编排（Agent Orchestration）：今天的新闻里出现了好几种不同的 Agent 协调策略 — Symphony 用"一 issue 一 Agent"的集中调度模式，MiMo-V2.5 走 1000+ 工具调用的长链条路线，Dirac 则是轻量终端脚手架打法。这些差异的核心是"编排模式"：你怎么分配任务、怎么协调多个 Agent、怎么处理工具调用链。理解编排模式很重要，因为今天 Agent 性能的瓶颈往往不是模型能力，而是协调设计 — 同一个模型在不同的编排架构下表现可以差出一个量级。
