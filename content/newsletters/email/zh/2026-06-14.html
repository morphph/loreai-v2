模型小课堂

模型权重（Model Weights）vs. API 访问：Fable 禁令之所以能一夜生效，是因为 API 访问可以用一条指令关停。但如果你下载了开源模型的权重（比如 Llama 或 Mistral），没有人能"关掉"它 — 文件在你硬盘上，跑不跑由你决定。这个区别 — 谁握着"关机键" — 现在是 AI 基础设施决策的核心问题。选 API 还是选自托管，本质上是在选便捷性还是自主权。
